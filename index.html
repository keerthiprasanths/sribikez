Google Drive Auto-Save Setup
Bills are automatically saved to Google Drive when you click Finish Service.
Step 1 — Go to script.google.com → New Project → delete existing code
Step 2 — Paste the code below → Save (Ctrl+S)
Step 3 — Click Deploy → New Deployment → Web App
   • Execute as: Me
   • Who has access: Anyone (not "Anyone with Google account")
Step 4 — Click Authorize access → allow → Copy the Web App URL
Step 5 — Paste URL below and click Save URL
function doPost(e) { try { var data = JSON.parse(e.postData.contents); var billNo = data.billNo || 'UNKNOWN'; var html = data.html; var month = data.month; var root = DriveApp.getRootFolder(); var folders = root.getFoldersByName('Sri Bikez Bills'); var main = folders.hasNext() ? folders.next() : root.createFolder('Sri Bikez Bills'); var mf = main.getFoldersByName(month); var mFolder = mf.hasNext() ? mf.next() : main.createFolder(month); mFolder.createFile(Utilities.newBlob(html,'text/html',billNo+'.html')); return ContentService .createTextOutput(JSON.stringify({status:'saved'})) .setMimeType(ContentService.MimeType.JSON); } catch(err) { return ContentService .createTextOutput(JSON.stringify({status:'error',msg:err.toString()})) .setMimeType(ContentService.MimeType.JSON); } } function doGet(e){ return ContentService.createTextOutput('OK').setMimeType(ContentService.MimeType.TEXT); }
Connection failed? The most common cause is CORS. Fix it:
1. In Apps Script editor → click Project Settings (gear icon)
2. Check "Show appsscript.json in editor"
3. In the editor, click appsscript.json → add this line inside the JSON:
"oauthScopes":["https://www.googleapis.com/auth/drive"]
4. Delete old deployment → create a New Deployment → copy new URL
No setup required. When you click Finish Service, the bill HTML file is automatically downloaded to your phone or computer. Then manually drag that file into your Google Drive folder. Simple and always works.
How it works:
1. Click Finish Service → bill file downloads automatically
2. Open drive.google.com on your phone/computer
3. Drag the downloaded file to the Sri Bikez Bills folder
4. Open the file anytime and print as PDF
